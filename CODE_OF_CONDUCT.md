# Code of Conduct

## Our Pledge

We want Pomodoro Timer to be a welcoming, respectful, and productive open source project.

Everyone participating in this project is expected to treat others with kindness and respect, regardless of experience level, background, identity, or point of view.

## Expected Behavior

Participants are expected to:

- Be kind, patient, and constructive.
- Respect different opinions and experiences.
- Give and receive feedback respectfully.
- Keep discussions focused on the project and the task at hand.
- Follow the project's contribution rules and review process.
- Use clear and respectful language in issues, pull requests, reviews, and discussions.

## Unacceptable Behavior

The following behavior is not acceptable:

- Insults, personal attacks, or disrespectful comments.
- Harassment, intimidation, or threats.
- Discriminatory language or behavior.
- Trolling, provocation, or intentionally disruptive participation.
- Publishing private information without permission.
- Ignoring the project's contribution process or repeatedly pushing changes outside the agreed workflow.

## Project Rules

All contributors must follow the process described in [`CONTRIBUTING.md`](CONTRIBUTING.md).

In particular:

- Work should start from an approved and assigned GitHub issue.
- Pull requests should target the `develop` branch.
- Reviews and requested changes should be handled respectfully.
- The project owner has the final decision on whether a contribution is accepted and merged.

## Enforcement

The project owner is responsible for clarifying and enforcing this Code of Conduct.

If someone behaves in a way that does not follow these rules, the project owner may take appropriate action, including:

- Asking the person to adjust their behavior.
- Closing issues or pull requests.
- Rejecting contributions.
- Limiting or removing participation in the project.

## Reporting

If you notice behavior that violates this Code of Conduct, please contact the project owner through the repository's GitHub issues or another available project contact channel.

Reports will be reviewed as fairly and respectfully as possible.
